TEXTRAW ARCADE — облачная версия для Netlify
================================================

Что добавлено
-------------
- Исправлена важная ошибка: если серверная функция Netlify ещё не подключена, страницы больше не прекращают запускаться из-за ошибки облачного запроса. Шесть встроенных игр и визуальный редактор должны открываться и в локальном режиме.
- Публичный общий каталог игр и приложений.
- Регистрация и вход по имени пользователя и паролю (без Google).
- Личные проекты, логика и переменные сохраняются в аккаунте.
- Сервер проверяет владельца перед изменением/удалением игры, приложения или личных данных.
- Данные хранятся в Netlify Blobs; отдельная база и отдельный сервер не нужны.
- Существующий дизайн и шесть встроенных мини-игр сохранены.

ВАЖНО: одного Netlify Drop недостаточно для серверных функций
------------------------------------------------------------
Netlify Drop публикует статические файлы. Для работы регистрации, общего хранилища и Netlify Functions нужно один раз подключить папку проекта к GitHub и связать репозиторий с уже существующим сайтом Netlify (либо публиковать через Netlify CLI). Сам сайт останется на Netlify.

Самый простой путь через GitHub
-------------------------------
1. Открой https://github.com/new и создай репозиторий, например textraw-arcade. Можно выбрать Private.
2. Распакуй этот ZIP на компьютере. В корне должны быть папки public и netlify, а также файлы package.json и netlify.toml. Загрузи СОДЕРЖИМОЕ папки проекта в корень репозитория — не загружай ZIP как единственный файл. На GitHub это можно сделать через Add file → Upload files.
3. Открой https://app.netlify.com/ и выбери свой существующий сайт TEXTRAW ARCADE.
4. В настройках сайта найди Project configuration / Build & deploy / Continuous deployment и подключи созданный GitHub-репозиторий. Если сайт уже подключён к другому репозиторию, не меняй его, пока не сохранишь копию текущего сайта.
5. В настройках Netlify открой Environment variables и добавь переменную:
   Name: TEXTRAW_SESSION_SECRET
   Value: придумай длинную случайную строку минимум из 32 символов (лучше 50–64). Не публикуй её и не помещай в файлы сайта.
6. Build settings должны использовать:
   Build command: npm install
   Publish directory: public
   Functions directory: netlify/functions
   Файл netlify.toml в этом архиве уже задаёт эти значения.
7. Запусти Deploys → Trigger deploy → Deploy site. Дождись окончания сборки.
8. Открой опубликованный сайт и зарегистрируй тестовый аккаунт. Имя пользователя: 3–20 символов, латинские буквы/цифры/подчёркивание. Пароль: от 8 символов.
9. Проверь: создай игру в студии, нажми «Добавить в игры», открой сайт в другом браузере/приватном окне и убедись, что игра видна без входа. Для публикации требуется аккаунт.

Ограничения текущей версии
--------------------------
- Приложения размером до 3,5 МБ каждое.
- HTML-код игры — до 600 КБ.
- Netlify Blobs хранит файлы между публикациями сайта, но бесплатные тарифы имеют ограничения и могут меняться.
- Нет восстановления пароля по почте, потому что вход сделан по имени пользователя без email. Сохрани пароль в надёжном месте.
- Не загружай опасные или чужие файлы. Файлы приложений не проходят автоматическую антивирусную проверку.
- Это начальная версия с базовой защитой паролей и владельцев. Перед большим публичным запуском желательно добавить лимиты запросов/защиту от массовых попыток входа и модерацию файлов.

Если встроенные игры или визуальный редактор не открываются
-----------------------------------------------------
В этой версии страницы больше не должны ломаться, если сервер временно недоступен. После распаковки проверь, что загружаешь ВСЕ файлы папки проекта, а не только public. Встроенные игры работают без аккаунта; визуальный редактор должен позволять добавлять объекты, сохранять проекты в текущем браузере и экспортировать HTML. Общая публикация и аккаунты заработают только после настройки Netlify Functions и Blobs.

Если сайт продолжает работать как раньше, а аккаунты не открываются
------------------------------------------------------------------
Обычно это означает, что сайт опубликован только через Netlify Drop без серверных функций, не задана переменная TEXTRAW_SESSION_SECRET или сборка не завершилась. Открой Netlify → Deploys и посмотри ошибки последней сборки.
